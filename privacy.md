## English

### 1. Scope and design

Reset is an offline-first self-management application for recovery from unwanted habits and addictive behaviours. The publisher does not provide a Reset account, advertising SDK, analytics service or cloud database. Core records are processed in the app's local database on the user's device.

Opening an external legal or support link, exporting a backup or PDF, or sharing a file is a deliberate user action. After information leaves Reset, the selected browser, sharing destination, backup provider or recipient applies its own privacy and security terms.

### 2. Data categories

Reset processes only the categories needed for features the user chooses:

- profile state, language, theme, privacy and accessibility settings;
- recovery target, behaviour category, goal and start date;
- urges, intensity, triggers, emotions, context, interventions and outcomes;
- check-ins, mood, adherence, journal, CBT and recovery notes;
- savings and reclaimed-time estimates;
- optional support-contact details and message templates;
- optional voice recordings and their local file references;
- local entitlement state; and
- bounded local diagnostics containing timestamp, platform, feature context, sanitized error message and component stack.

These records may reveal health, addiction, sexual-life or financial circumstances and can therefore be sensitive or special-category data under applicable law.

### 3. Purposes and legal grounds

The data is used to provide the user's selected recovery tools, calculate local timers and summaries, generate on-device insights, restore user-created backups, protect the interface, schedule optional reminders, and diagnose failures locally.

Before sensitive records are entered, Reset separately provides this notice, requests explicit consent for local sensitive-data processing, requests acceptance of the Terms of Use, and requires an 18+ declaration. Consent can be withdrawn at any time by using the deletion control described below. Where another mandatory legal basis or consumer right applies, this notice does not limit it.

### 4. Recipients, transfers and selling

Reset does not automatically transmit core records to the publisher or third parties. It does not sell personal information, run behavioural advertising or use cross-app tracking. There is no publisher-operated international transfer in the current build. User-initiated exports and external links are transfers chosen by the user.

### 5. Permissions

- **Microphone:** requested only after the user taps Record, solely to create an optional local voice note.
- **Notifications and boot completion:** used for optional reminders selected by the user. Privacy mode can hide sensitive notification content.
- **Biometrics:** the operating system confirms device authentication; Reset does not receive or store biometric templates.
- **Vibration/haptics:** used for optional interaction feedback and crisis exercises.

Permissions can be refused or revoked in device settings. Core manual tracking remains available without optional microphone, notification and biometric features.

### 6. Retention, deletion and portability

Records remain until the user edits or deletes them, clears app storage, uninstalls the app according to the operating system's behaviour, or imports a replacement backup. Settings provides JSON/PDF export and a permanent delete-all action. Delete all removes database tables, referenced local recordings, local diagnostics and legacy local stores. If the operating system refuses deletion of a media file, Reset reports the number of failed files instead of claiming complete deletion.

Backups and reports exported by the user are not deleted from their destination when Reset's local data is deleted. The user must remove those copies separately.

### 7. Security

Reset uses the operating system's app sandbox, optional biometric interface lock, privacy shield, notification-content hiding, validated backup schemas and an offline build check. No software can promise absolute security. Device compromise, insecure backups, unlocked-device access and user-selected sharing destinations remain risks. The local SQLite database is not described as end-to-end encrypted.

### 8. Rights and choices

The user can view and correct entries in the app, export records, disable optional permissions, withdraw consent and delete local records. Because the publisher does not operate an account or receive the local database, it normally cannot identify or retrieve a user's on-device records. Questions about the notice can be raised through the support channel without posting sensitive content. Statutory rights under applicable data-protection and consumer law remain unaffected.

### 9. Children

Reset is intended only for people aged 18 or older. It is not directed to children and should not be used to enter a child's sensitive data.

### 10. Medical and emergency boundary

Reset is not a medical device, healthcare provider, diagnosis, treatment, emergency service or promise of recovery. Automated insights are estimates based on user entries and may be incomplete or wrong. Severe alcohol or substance withdrawal, overdose, seizures, chest pain, loss of consciousness, or risk of self-harm requires immediate local emergency help and qualified professional care.

### 11. Changes

Material changes receive a new document version. The app requires a fresh, separate acknowledgement and consent before continued sensitive-data processing under the new version.
